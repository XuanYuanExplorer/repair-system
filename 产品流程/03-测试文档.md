## 1. 测试范围

### 1.1 范围内

- 全部 REST 接口（鉴权、报修、缴费、寝室、值日、公告、消息、个人、反馈、帮助）。
- 21 个页面的展示、交互、三态（加载/空/错误）与权限可见性。
- 核心链路：登录 → 报修 → 跟踪 → 确认评价；缴费（单笔/合并）→ 结果 → 记录；设施故障 → 一键报修。
- 异步与并发：时段抢订、支付幂等、重复提交、状态竞争、定时任务效果。
- 安全：越权（IDOR）、横向/纵向提权、上传攻击、短信轰炸、金额篡改。
- 非功能：响应时间、并发承载、移动端适配。

### 1.2 范围外（不测或仅冒烟）

| 项 | 原因 |
|---|---|
| 真实微信/支付宝支付 | MVP 用 Mock 网关，S3 接入后单独出支付专项测试 |
| 微信扫码登录 | P2 功能，入口置灰 |
| 维修工端 App | 本期无客户端，后台代操作 |
| 校方统一身份认证（CAS） | 未接入 |
| 真实短信到达率 | 用 Mock provider，只测流程与限流 |

```yaml
# .github/workflows/ci.yml
name: ci
on: [push, pull_request]

jobs:
  backend:
    runs-on: ubuntu-latest
    services:
      mysql:
        image: mysql:8.0
        env: { MYSQL_ROOT_PASSWORD: root, MYSQL_DATABASE: dorm_test }
        ports: ["3306:3306"]
        options: --health-cmd="mysqladmin ping" --health-interval=5s --health-retries=10
      redis:
        image: redis:7
        ports: ["6379:6379"]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.11" }
      - run: pip install -e ".[dev]"
      - run: ruff check app && mypy app
      - run: alembic upgrade head && alembic downgrade -1 && alembic upgrade head
      - run: pytest --cov=app/services --cov-fail-under=85 -q

  frontend:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
        with: { version: 9 }
      - run: pnpm install --frozen-lockfile
      - run: pnpm lint && pnpm typecheck
      - run: pnpm test:unit -- --coverage
      - run: pnpm build

  e2e:
    needs: [backend, frontend]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: docker compose -f docker-compose.test.yml up -d
      - run: npx playwright test --reporter=html
      - uses: actions/upload-artifact@v4
        if: failure()
        with: { name: playwright-report, path: playwright-report }
```

## 15. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 真实支付接入延迟 | S3 阻塞上线 | Mock 网关与真实网关同一接口，切换只改配置；提前 2 周启动商户资质 |
| 时段容量与真实维修排班不符 | 学生选了没人上门 | 容量参数配置化，宿管后台可调；超时任务兜底提醒 |
| 寝室长权限判定依赖 `leader_id` 单点 | 换寝室长后越权 | 换人时同步更新 `leader_id` 并写审计；接口每次实时查库不缓存 |
| 短信通道被封或延迟 | 注册/重置不可用 | 供应商双活；失败降级为「语音验证码」或线下核验 |
| 数据迁移出错 | 住宿绑定错乱 | 迁移前后行数与抽样比对；保留回滚 SQL；灰度 1 栋楼先行 |
| 并发压测发现 DB 瓶颈 | 开学季卡顿 | 索引复核（§4.3）、首页聚合 60s 缓存、读写分离预案 |
| 设计稿与实现视觉漂移 | 验收返工 | 建立 21 页视觉基线截图，CI 中做像素 diff（容差 0.5%） |
